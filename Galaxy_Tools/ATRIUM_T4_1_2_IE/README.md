# ATRIUM T4.1.2 Information Extraction

This direcotry contains a Galaxy tool which implements the Information Extraction (IE) component of the workflow developed for task 4.2.1 of the ATRIUM project. The narrative workflow description can be found on the [SSH Open Marketplace](https://marketplace.sshopencloud.eu/workflow/IrpmkB).

The main difference between this tool and the main pipeline script in the root of the repository is that the tool works on just a single JSON input file and produces a single JSON output file
